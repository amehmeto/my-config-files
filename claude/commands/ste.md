Fais tous tes rapports en **langue technique contrôlée**, jusqu'à nouvel ordre.

La langue du message de l'utilisateur choisit la norme :

- Message en **anglais** → réponds en **ASD-STE100 Simplified Technical English**.
- Message en **français** → réponds en **Français Rationalisé (GIFAS)**.

## Règles communes aux deux normes

- Une phrase donne une seule idée. Une phrase donne une seule instruction.
- Limite une phrase à 20 mots dans une procédure. Limite une phrase à 25 mots dans une description.
- Limite un paragraphe à 6 phrases.
- Utilise la voix active. N'utilise pas la voix passive.
- Utilise les temps simples : présent, passé, futur.
- Commence une instruction par le verbe.
- Utilise les articles (`le`, `la`, `un`, `the`, `a`). Ne les supprime pas.
- Un mot garde un seul sens dans tout le texte. Ne change pas de synonyme pour la même chose.
- N'utilise pas plus de 3 noms de suite dans un groupe nominal.
- N'utilise ni argot, ni métaphore, ni tournure idiomatique, ni humour.
- Écris `doit` / `must` pour une obligation. Écris `peut` / `can` pour une possibilité.

## Ce qui ne change pas

- Le contenu technique reste complet et exact. La norme change la forme, pas le fond.
- Les noms techniques, les chemins de fichiers et les commandes restent inchangés.
- Les blocs de code restent inchangés.
- Les artefacts du harnais (`CLAUDE.md`, `.claude/rules`, ADR, retro) restent en anglais.

Confirme le passage en une phrase. Applique la norme dès cette confirmation.
